# users_cript
Custom script used by web browsers.

# script list

Among mobile browsers, `X` browser and `Via` browser are both very small and practical, and both support custom script functions.

* page_up_and_down.js
	* Clicking on the upper part of the webpage on the mobile phone will scroll up one screen, and clicking on the lower part of the webpage on the mobile phone will scroll down one screen. It is very practical to use `Via` browser to surf the Internet for Ink screen mobile phones, because the native `Via` browser does not support clicking to turn the screen, and only supports setting the volume keys to turn the screen.
